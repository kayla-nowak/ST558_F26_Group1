Return people who managed a team and were inducted into the hall of fame (regardless of their hall of fame category). Return all 9 columns used in the previous 2 questions.

Note: Summarize function drops anything not in the group_by() statement. As such, tackle the Manager data first, then join with People and Hall of Fame data. Summarize also requires collect() to be called prior to to summarizing. This means that each data element for the join must |> collect() to ensure X:Y source agreement.

Note: This code completes the full return in one big, nested join. Alternatively, each database return could be saved as its own R object (tibble), and then dplyr join could simply reference the objects.

inner_join(
  
  #Top X = Managers + names from People
  left_join(#Nested X = Managers, fully processed 
            tbl(con, "Managers") |>
              select(playerID, G, W, L) |> collect() |>
              group_by(playerID) |>
              summarize(G_managed = sum(G, na.rm = TRUE),
                        Total_W = sum(W, na.rm = TRUE),
                        Total_L = sum(L, na.rm = TRUE),
                        Career_WL_Pct = Total_W/G_managed) |>
              arrange(desc(Career_WL_Pct)),
            #Nested Y = People, just to pick up names
            tbl(con,"People") |> 
              select(playerID, nameFirst, nameLast) |> 
              collect(),
            #Nested by playerID (for left join)
            by="playerID"),
  
  #Top Y = Hall of Fame, fully processed
  tbl(con, "HallOfFame") |> 
    filter(inducted=="Y") |> 
    select(playerID, yearID, category) |>
    collect(),
  
  #Top By playerID (for inner join)
  by="playerID") |>
  #Order Variables
  select(nameFirst, nameLast, playerID, yearID, category, everything())
