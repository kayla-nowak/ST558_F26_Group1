  1. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

    Long format data is structured with more rows, where each row consists of one observation and each column consists of one variable. Wide format data has a single row per subject and may have more than one observation in a given row (more columns). Generally we prefer long format as most software is built to deal with data formatted this way.
