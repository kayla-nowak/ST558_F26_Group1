Task 1: Conceptual questions

1.

Writing the following nested function using the baseR chaining operator.

library(tidyverse)
arrange(filter(select(as_tibble(iris), starts_with("Petal"), Species), Petal.Length <
1.55), Species)

Now using the pipe operator

as_tibble(iris) |>
  select(starts_with("Petal"), Species) |>
  filter(Petal.Length < 1.55) |>
  arrange(Species)

2.

The long format data is the one that will increase the number of rows and decrease the number or columns, while the wide format data, widens the data by increasing the number of columns and decreasing the number of rows.

For statistical analysis is preferred to use the long format data, since we can get in each row an observation.
