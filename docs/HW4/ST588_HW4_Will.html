2. Long Format and Wide Format Data

Wide format gives each variable its own column with one row per unique record. Long format gives each row a single observation so one subject spans multiple rows instead of multiple columns. Long Format is generally preferred for analysis. Modeling functions expect one row per observation so long format is more intuitive for this.

Managers win-loss records.

manager_records <- tbl(con, "Managers") |> 
                      select(playerID, G, W, L) |>
                      group_by(playerID) |>
                      summarize(G_managed = sum(G, na.rm = TRUE),
                                Total_W = sum(W, na.rm = TRUE),
                                Total_L = sum(L, na.rm = TRUE)) |> 
                      collect() |>
                      mutate(win_loss = Total_W / G_managed) |>
                      arrange(desc(win_loss))
