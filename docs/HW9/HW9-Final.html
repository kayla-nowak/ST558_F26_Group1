6. Summary Statistics

To avoid repeating the same summarize() code for each grouping, we write a helper that summarizes bike count by whatever grouping variables we pass it.

bike_summary <- function(data, ...) {
  data |>
    group_by(...) |>
    summarize(
      n      = n(),
      total  = sum(bike_count),
      mean   = mean(bike_count),
      sd     = sd(bike_count),
      min    = min(bike_count),
      median = median(bike_count),
      max    = max(bike_count),
      .groups = "drop"
    )
}

Fitting MLR Models

Weekday/Weekend Variable

We don’t use date directly in the models, but we use it to create a weekday/weekend factor. We need this variable in the training set, the test set, and later the full data, so we write it once as a function. wday() with week_start = 1 numbers Monday as 1 through Sunday as 7, so days 6 and 7 are the weekend.

add_day_type <- function(df) {
  df |>
    mutate(
      day_type = factor(
        if_else(wday(date, week_start = 1) >= 6, "Weekend", "Weekday")
      )
    )
}

bike_train <- add_day_type(bike_train)
bike_test  <- add_day_type(bike_test)

Standardize the Numeric Variables

Each numeric predictor is standardized by subtracting its mean and dividing by its standard deviation. The means and standard deviations come from the training set and are applied to both training and test. The test set is never used to compute them, so no information from it leaks into the model. The response, bike_count, stays on its original scale.

We write a helper that takes a reference data set, the data to standardize, and the response to leave alone. We reuse it later to standardize the full data with its own means and standard deviations.

standardize_tibble <- function(reference, data, response) {

  # Means and SDs of every numeric predictor in the reference data
  ref_mean <- reference |>
    summarize(across(where(is.numeric) & !{{ response }}, mean))
  ref_sd <- reference |>
    summarize(across(where(is.numeric) & !{{ response }}, sd))

  cols <- names(ref_mean)

  # Standardize each column using the reference values
  data |>
    mutate(across(
      all_of(cols),
      ~ (.x - ref_mean[[cur_column()]]) / ref_sd[[cur_column()]]
    ))
}
bike_train_std <- standardize_tibble(bike_train, bike_train, bike_count)
bike_test_std  <- standardize_tibble(bike_train, bike_test,  bike_count)

We predict on the standardized test set and compute the RMSE for each model with yardstick::rmse_vec(). The best model is the one with the lowest test RMSE.
