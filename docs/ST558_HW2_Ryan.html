Task 1: Basic Vector Practice

First, we create two vectors corresponding to the blood pressure of 20 subjects. The first, pre_bp is pre-treatment measurements, and the second, post_bp is post-treatment measurements.

pre_bp <- c(130, 128, 116, 124, 133, 134, 118, 126, 114, 127, 141, 138, 
            128, 140, 137, 131, 120, 128, 139, 135)

post_bp <- c(114, 98, 113, 99, 107, 116, 113, 111, 119, 117, 101, 119,
             130, 122, 106, 106, 124, 102, 117, 113)

is.vector(pre_bp)
[1] TRUE

Next, we will assign names to the vector elements using this paste() function

patient <- c(paste("Subject", 1:20, sep = "_"))
names(pre_bp) <- patient
names(post_bp) <- patient
print(head(pre_bp))
Subject_1 Subject_2 Subject_3 Subject_4 Subject_5 Subject_6 
      130       128       116       124       133       134

We can calculate the change in blood pressure by subtracting post-treatment measurements from pre-treatment measurements.

diff_bp <- pre_bp - post_bp
names(diff_bp) <- patient

Now, we can calculate the average decrease in blood pressure across all patients

mean(diff_bp)
[1] 17

From this data, blood pressure decreased 17 bpm, on average, after treatment.

We can specifically determine which patients experienced a decrease in blood pressure after treatment (positive change) using the which() function

which((diff_bp) > 0)

We can see that all patients experienced a decrease in blood pressure after treatment except for subject 9, 13, and 17. Therefore, we can make a vector that is a subset of the differences to only include subjects whose blood pressure decreased.

positive_diff_bp <- diff_bp[which((diff_bp) > 0)]

mean(positive_diff_bp)
[1] 20.64706

From this subset of only subjects who experienced a decrease in blood pressure after treatment, the average decrease for this sample was 20.647 bpm

Task 4: Control Flow Practice

Let’s characterize the post-treatment (or placebo) bp measurement as optimal (<=120), borderline (120 < bp <= 130), and high (>130) by creating a new status column and using a loop with if/then/else logic

my_list$treatment$status <- character(20) # Create a new empty character column

for (i in 1:length(my_list$treatment$post_bp)) { #Reference my_list, not the original object
  if (my_list$treatment$post_bp[i] <= 120) {
    my_list$treatment$status[i] <- "Optimal"   # Assign values to the empty character column within the loop
  } else if (my_list$treatment$post_bp[i] <= 130) {
    my_list$treatment$status[i] <- "Borderline"
  } else {
    my_list$treatment$status[i] <- "High"
  }
}
