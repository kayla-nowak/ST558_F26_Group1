Task 4: Writing a function

8.

We are going to write a function to get the interquartile range of a vector, we use names = F to remove the percentages names. And add ... to allow unamed arguments for the quantile function.

getIQR <- function(v, ...){
  
  quantile(v, names = F, ...)[4] - quantile(v, names = F, ...)[2]
  
  
}

We are going to write a function to get the coefficient of variation

getCoefVar <- function(v, ...){
  
  sd(v, ...) / abs(mean(v, ...))
  
}

12.

We need to create a wrapper function that return the IQR and the coefficient of variation for a given vector. The output is a list with both of the values calculated.

getSummaries <- function(v, ...){
  
  list(IQR = getIQR(v, ...), Coef_Var = getCoefVar(v, ...))
  
}
