Task 1: Conceptual Questions

  1. If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

    You would need to specify ‘../MyData.csv’ as this is located one level up from the working directory.

  2. What are the major benefits of using R projects?

    The working directory for R projects is set to the project’s root folder. This makes it easy for when you have multiple users working on the project due to the relative file paths being consistent between machines. Pathing does not break between machines. Related files are self contained.

  3. What is Git and what is GitHub?

    Git is a software that tracks files, changes to those files, allows you to branch to silo work and merge code changes safely. Github is a cloud hosting platform for git repos with some additional tooling for tracking, approvals, permissions policies, etc.

  4. What are the two main differences between a tibble and a data.frame?

    Printing a tibble only prints the first several rows whereas printing a data.frame will print all rows of that object. They differ in subsetting. Tibble does not allow for partial matching on column names with ‘$’ whereas a data.frame can partially match a column name.

8.

IQR function.

getIQR <- function(x, ...) {
  q <- quantile(x, probs = c(0.25, 0.75), ...)
  unname(q[2] - q[1])
}
