Task 1: Conceptual Questions

  1. If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

    We can use ../MyData.csv, typically inside a read.csv() function. The .. prefix means we go up one level from our current working directory, putting us inside myfolder

  2. What are the major benefits of using R projects?

    When an R project is created, it gets associated with a directory (folder or repo) and uses this as the projects working directory. This is very useful, because if we have this repo shared (via Github), other users can pick up the same R project and all the paths should work. This allows for organization and seamless collaboration.

  3. What is Git and what is GitHub?

    Git is the actual software that performs version contolling. whereas Github is the online hosting service for projects that utilize Git software. Version controlling allows us to save every change that occurs in our project folder, and revert back to previous saves.

  4. What are the two main differences between a tibble and a dataframe?

    Tibbles are a modern re-imagining of the data frame. When printing a tibble, we only see the first few rows/columns, whereas printing a dataframe prints everything to the console. Tibbles also force you to confront problems earlier when subsetting, as they dont do partial matching. df$colnam on a dataframe will match a column named colname, whereas with a tibble it warns you explicitly the column doesn’t exist

Task 4: Writing a Function

8. IQR function

We start this task by writing a basic function to get the IQR from a vector of numbers using the quantile function

getIQR <- function(vector, ...) { # ... Allows other unnamed arguments to be passed
  
  q <- quantile(vector, probs = c(0.25, 0.75), names = F, ...) 
  # Saving this as q allows us to only have to use `quantile` once
  return(q[2] - q[1])
}

10. Coefficient of variation function

Let’s write another function that returns the coefficient of variation of a vector, defined as the sample standard deviation divided by the absolute value of the sample mean.

getCoefVar <- function(vector, ...){
  return((sd(vector, ...)) / abs(mean(vector, ...)))
  }

12. Wrapper function

Now, let’s write a function getSummaries() that takes in a vector and returns both the IQR and the coefficient of variation by calling both of these previous functions

getSummaries <- function(vector, ...){
  
  return(list(IQR = getIQR(vector, ...), Coef_Var = getCoefVar(vector, ...)))
}
