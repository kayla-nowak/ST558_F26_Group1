Task 1: Conceptual Questions

  1. If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

    You would need to specify ‘../MyData.csv’ as this is located one level up from the working directory. The ‘../’ prefix moves you up one level from current into ‘myfolder/’ where ‘MyData.csv’ lives.

  2. What are the major benefits of using R projects?

    The working directory for R projects is set to the project’s root folder. Relative file paths stay consistent no matter whose machine is being used for the project. This makes collaboration more seamless without paths breaking. Relative paths are very helpful for code sharing, and version control is also helpful for code sharing. Through an R project for version control we can clone a Git repository and manage that repository through R Studio’s terminal. Related files are self contained.

  3. What is Git and what is GitHub?

    Git is a software that tracks files, changes to those files, allows you to branch to silo work and merge code changes safely. Github is a cloud hosting platform for git repos with some additional tooling for tracking, approvals, permissions policies, etc.

  4. What are the two main differences between a tibble and a data.frame?

    Printing a tibble only prints the first several rows and size summary (#rows x #cols), whereas printing a data.frame will print all rows of that object. They differ in subsetting. Tibble does not allow for partial matching on column names with ‘$’ whereas a data.frame can partially match a column name.

Task 4: Writing Functions

8.

IQR function.

getIQR <- function(x, ...) {
    #q stores P25 and P75 as vector elements, names disabled
    q <- quantile(x, probs = c(0.25, 0.75), names=FALSE)
    
    #iqr captures the calculated difference:  P75 - P25
    iqr <- q[2] - q[1]
    return(iqr)
}

getCoefVar <- function(x, ...) {
  sd(x, ...) / abs(mean(x, ...))
}

  c(IQR = getIQR(x, ...), 
  CoeVar = getCoefVar(x, ...))
